# Portfolio Mahmud Huseynov

Bron van mijn portfolio, live op **<https://mahmud-huseynov.github.io/>**.

Eén statische pagina (`index.html`) zonder build-stap of framework, gehost met GitHub Pages. Afbeeldingen staan in `images/`.

## Lokaal bekijken

```bash
python3 -m http.server 8765
```

Open daarna <http://localhost:8765>.

## Als pdf opslaan

Open de pagina in Chrome en kies **Afdrukken → Opslaan als pdf**. De pagina heeft een eigen opmaak voor afdrukken: zonder menu en met de volledige link achter elke externe link.
